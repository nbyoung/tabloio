usage: tabloio [-C <dir>] tableau [<options>]

How does the whole project stand?

  -C <dir>               Run as if started in <dir>, the directory that holds .tableaux
  --ref <ref>            Read the project at this commit; history also takes <from>..<to>
  --level <level>        Write at glance (the default), detail or provenance
  --markdown             Write Markdown (the default)
  --text                 Write Unicode text
  -o, --output <file>    Write to <file>; - is standard output (the default)
  --person <email>       Focus on one person
  --window <n>           Show <n> gate columns either side of the next gates in view
  --columns <gates>      Show these gate columns: gate keys joined by commas
  --historical           Show the marks of historical junctions
  -h, --help             Print this text
